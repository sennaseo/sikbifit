# 포트폴리오 프로젝트 설명

## 프로젝트명

식비핏

라이브 URL: https://sikbifit.netlify.app

## 한 줄 소개

자취생과 직장인을 위한 SEO형 월 식비 예산 계산기

## 문제 정의

식비는 매달 체감 지출이 크지만, 사용자가 본인의 식사 패턴을 숫자로 빠르게 점검할 수 있는 가벼운 도구는 많지 않습니다. 특히 자취생과 사회초년생은 복잡한 가계부보다 즉시 결과를 보여주는 계산기를 선호합니다.

## 해결 방법

식비핏은 외식, 배달, 장보기, 카페 횟수를 기반으로 월 예상 식비를 계산하고, 목표 예산과의 차이를 보여줍니다. 결과에 따라 절약 루틴과 장보기 체크리스트를 제공해 사용자가 바로 행동할 수 있게 설계했습니다.

## 주요 기능

- 월 식비 계산
- 예산 초과 여부 진단
- 절약 힌트 제공
- 장보기 체크리스트 생성
- 결과 공유
- localStorage 저장
- SEO FAQ와 광고/제휴 CTA 영역

## 기술 스택

React, TypeScript, Vite, CSS, localStorage, Web Share API

## 수익화 실험

결과 하단에 AdSense 광고 슬롯을 두고, 절약 힌트 아래에 장보기/밀프렙 제휴 CTA를 배치했습니다. 사용자가 계산 결과를 확인한 뒤 자연스럽게 탐색할 수 있는 위치를 선택했습니다.

## 배운 점

작은 기능이라도 검색 의도, 첫 화면 사용성, 공유 동선, 수익화 위치를 함께 설계하면 배포 가능한 미니 서비스로 완성도가 올라갑니다.

## SNS 홍보 문구

월급은 그대로인데 식비만 계속 늘어난다면? 식비핏에서 30초 만에 이번 달 예상 식비를 계산해보세요. 외식, 배달, 장보기 패턴만 넣으면 절약 포인트까지 바로 알려줍니다.
